# Security Policy

This is a synthetic-data demo using a fictional operator, fictional
regions, and fictional events. It contains no real sensor feeds, no
real events, no network calls, and no alerting integrations.

- Report vulnerabilities privately via GitHub's private vulnerability
  reporting for this repo.
- Never submit real sensor data, real locations of sensitive sites,
  or real personal data in an issue or pull request.
- Escalations in this demo are simulated only: they change simulated
  state, and every escalation requires a named human approval.
